# Reglas del proyecto `stockflow-pos`

- Stack: **Python 3.12+**, **FastAPI**, **SQLAlchemy 2.x**, **PyJWT** y **`uv`**.
- Código interno (archivos, modelos, funciones, rutas de API) en **inglés técnico**.
- Documentación (`README.md`), interfaz web y mensajes al usuario en **español** (moneda en Soles `S/` e IGV 18%).
- Nunca subas archivos `.env` ni bases de datos `.db` al repositorio.
- Consulta las skills en `.agents/skills/` para arquitectura (`arquitectura-pos`) y reglas críticas de negocio (`reglas-negocio-pos`).
